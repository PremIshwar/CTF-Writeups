Hi! Welcome to my writeup on SherpaCTF 2025. As mentioned in the title, this CTF was fully offline, meaning no AI or even Google, although printed notes were allowed. This CTF was the first of its kind in Malaysia and it was a quite a new experience. However, I did manage to get into the finals and scored 7th place!

## Game Format

The format of this CTF was not Jeopardy or Attack and Defence. We were given a Kali Linux virtual machine OVA file to setup on our laptops. That's right, we weren't even allowed to use our own environments! We were given the username "zero" with the password "welcome". Each user has a challenge that, when solved, gives us the credentials for the next user (one, two, three...). The goal of the CTF is to get to the highest user as fast as possible. I made it to user "seventeen" out of "twentyfour". Some of these challenges were pretty straightforward and some required some trial error, especially since we couldn't Google anything. This writeup will cover users "zero" to "sixteen", however I will do the rest if time allows it. Let's get right into it!
